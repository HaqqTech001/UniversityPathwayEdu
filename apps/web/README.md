# UPEC Web Application

This directory now contains a complete copy of the existing public website and student portal, including its source files, Vite configuration and public assets.

The root-level web application remains available during the migration for deployment compatibility. The independent `apps/web` build should be verified before switching production deployment to this directory.

From `apps/web`, install dependencies and run `npm run dev` or `npm run build` after its package manifest is in place.
